🗺️ Roadmap Pembinaan Website

Dari 19 HTML mockup ke production website — 6 fasa, ~12 minggu, stack yang practical untuk Malaysia.

📅 Mulai: Jul 2026 ⏱️ Estimasi: 12 Minggu 💰 Budget: RM5K–25K 👥 Team: 1–3 orang

📍 Di Mana Kita Sekarang

✅ Semua mockup siap — 19 file HTML/CSS/JS, calculator interaktif, portal demo, dashboard demo, map, referral generator. Ini adalah blueprint lengkap — sekarang perlu convert ke code sebenar dengan backend, database, dan integrasi.

🛠️ Keputusan Tech Stack

Frontend Framework

Next.js 14+ (App Router) Recommended

✅ Site asal dah guna Next.js

✅ SSR + static hybrid — SEO friendly

✅ Vercel deploy 1-click

✅ API routes built-in

✅ TypeScript support

Alternatif: Remix / Nuxt

Remix: Bagus tapi ecosystem kecil

Nuxt: Kalau team lebih biasa Vue

⚠️ Perlu migrate semua mockup

Database

Supabase (PostgreSQL) Recommended

✅ Free tier generous

✅ Auth + OTP built-in

✅ Real-time subscriptions

✅ Row Level Security (PDPA)

✅ Dashboard admin ready

Alternatif: PlanetScale + Prisma

PlanetScale: MySQL-compatible, bagus untuk scale

⚠️ Free tier limited sejak 2024

⚠️ Perlu separate auth solution

Payment Gateway

Billplz Recommended

✅ FPX + e-wallet (TnG, Boost, GrabPay)

✅ Fee rendah (1.5% FPX)

✅ Malaysia-based, BM support

✅ Recurring payment support

Alternatif: Stripe / ToyyibPay

Stripe: Global tapi fee tinggi (2.9%+30¢)

ToyyibPay: Murah tapi limited features

⚠️ Stripe perlu SSM registration

SMS / OTP

Infobip / Vonage Recommended

✅ Malaysia coverage kuat

✅ OTP flow built-in

✅ Competitive pricing MY routes

Alternatif: Twilio

Global standard, docs bagus

⚠️ MY SMS lebih mahal

⚠️ Delivery rate MY kadang slow

📅 6 Fasa Pembinaan

Fasa 1

Foundation & Auth

⏱️ Minggu 1–2

🎯 Goal: Next.js project live + OTP login berfungsi

  • Initialize Next.js 14 App Router project
  • Setup Tailwind CSS — convert mockup styles to components
  • Setup Supabase project — tables, RLS policies
  • OTP login flow: nombor telefon → SMS OTP → verify → session
  • Middleware: redirect authenticated users to dashboard
  • Consent table: 3 toggle per user (wifi, eastel_marketing, owner_marketing)
  • Deploy ke Vercel — custom domain + SSL

Deliverable: User boleh login dengan nombor telefon + OTP. Dashboard kosong accessible.

Next.jsSupabase AuthInfobipVercel
Fasa 2

Captive Portal + CRM

⏱️ Minggu 3–5

🎯 Goal: Tetamu boleh sambung WiFi, owner nampak lead real-time

  • Captive portal page (production): phone → OTP → 3 consent → connected
  • 60 saat free internet flow (sebelum gate)
  • 30 minit session timer (server-side)
  • Lead capture → simpan ke Supabase leads table
  • Analytics Engine: rate limit OTP, auto-gantung spam
  • Owner dashboard: lead list real-time (Supabase Realtime)
  • Lead status tagging: Hot / Warm / Cold / Baru
  • Consent log: simpan setiap consent event (PDPA audit trail)
  • CSV export untuk owner (lead data + consent history)
  • "STOP EASTEL" opt-out handler → update consent → stop all marketing

Deliverable: Captive portal berfungsi penuh. Owner nampak lead masuk real-time.

Next.js RoutesSupabase RealtimeAPI RoutesInfobip

⚠️ Captive portal router integration — ini part paling teknikal. Perlu configure router firmware (OpenWrt/dd-wrt) atau guna hardware yang support Walled Garden. Cadangan: mula dengan web-based portal dulu (redirect DNS), baru kemudian integrate hardware.

Fasa 3

Payment + SIM Order

⏱️ Minggu 6–7

🎯 Goal: User boleh bayar RM9.90/bln & tempah SIM

  • Integrate Billplz — FPX + e-wallet checkout
  • Subscription recurring: RM9.90/bulan auto-charge
  • Free trial flow: 7 hari → upgrade prompt → payment
  • SIM order form → simpan ke orders table
  • Order tracking: status workflow (Diterima → Diproses → Dalam Penghantaran → Diterima)
  • Webhook dari kurir (J&T/NinjaVan) → auto update tracking
  • WhatsApp notification: order confirm, tracking number, SIM activated
  • Grace period handler: payment gagal → 7 hari → downgrade ke Free

Deliverable: Full checkout flow. Subscription recurring berfungsi. SIM order tracked.

Fasa 4

Komisen Engine + Referral

⏱️ Minggu 8–9

🎯 Goal: Komisen dikira auto, referral link berfungsi

  • Referral link generator: unique ID per user → UTM tracking
  • Referral attribution: lead dari referral link → credit ke referrer
  • Komisen engine: RM3/active referral/bulan — cron job hari ke-15
  • Revenue Sharing calculator → actual payout (T1-T3 formula)
  • Onboarding Bonus → auto calculate berdasarkan blok
  • ESK Bonus → Level 1-3 calculation
  • Komisen dashboard: ringkasan, breakdown, belum dibayar
  • Withdrawal request → minimum RM50 → approve & bank transfer
  • Fraud detection: self-referral block, phantom referral flag
  • 4 calculator interaktif → share WhatsApp deep link

Deliverable: Komisen dikira & dibayar automatik. Referral viral loop berfungsi.

Fasa 5

Polish + SEO + Analytics

⏱️ Minggu 10–11

🎯 Goal: Website ready untuk launch — SEO, analytics, performance

  • Mobile responsive audit — test on 10+ devices
  • Accessibility audit (WCAG 2.1 AA)
  • Wakil Kawasan map — Leaflet with real data from Supabase
  • QR code generator — real QR with referral link
  • 404 page, loading states, error boundaries
  • Rate limiting & security headers

Deliverable: Production-ready website. SEO score 90+. Analytics tracking all events.

🚀 Langkah Seterusnya — SEKARANG

✅ 7 perkara yang perlu buat MINGGU INI untuk mula Fasa 1:

  1. Register SSM — EastelPro Sdn Bhd (jika belum). Wajib untuk Billplz, custom domain, dan legal.
  2. Register Supabase account — free tier. Create project "eastelpro-prod". Dapat URL + anon key + service key.
  3. Initialize Next.js project — npx create-next-app@latest eastelpro --typescript --tailwind --app
  4. Register Infobip account — free trial. Dapat API key untuk SMS OTP Malaysia.
  5. Register Billplz account — perlukan SSM. Dapat API key + X-Signature key.
  6. Beli domain eastelpro.com — ~RM50–80/tahun. Point DNS ke Vercel.
  7. Semak dengan peguam — struktur komisen T1-T3 + ESK perlu review KPDN/AJL.

⚠️ Jangan launch iklan sebelum Fasa 1–3 siap & UAT. Tanpa payment + portal berfungsi, traffic akan bounce dan burn budget.
